# Evidence Card 03

- **Card ID：** EC-03
- **教學主題：** Direct Prompt Injection
- **核心主張：** Direct Prompt Injection 的攻擊指令由主要使用者直接透過 query／input 送入；AgentDojo 描述為使用者輸入試圖覆蓋 system prompt。（S1，PDF p. 3；S2，PDF p. 2）
- **簡短初學者解釋：** 使用者直接在聊天輸入企圖蓋過原任務的新命令，屬於直接輸入型的例子。
- **對應 Wiki 頁面：** `wiki/03-direct-vs-indirect.md`
- **來源 ID：** S1、S2、S5
- **PDF 頁碼：** S1 p. 3（含註 1）；S2 p. 2；S5 p. 2
- **可用於哪一頁簡報：** 第 3 頁：Direct 與 Indirect 對照的 Direct 欄
- **限制 / 不可過度延伸的地方：** 分類用語存在差異：S1 轉述 NIST 時指出不同段落對 Direct Prompt Injection／Direct Prompting Attack 的關係不完全一致；S5 將常見直接使用者輸入稱為 User Prompt Injection Attack，並提到常被稱作 jailbreaking。簡報須並列來源說法，不宣稱只有一種分類。
